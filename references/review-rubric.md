# Plottr Story Review Rubric

Use this checklist after reading the project broadly enough to understand the target material in context.

## 1. Preserve strengths first

Identify 3-8 elements that should survive revision, such as:
- a strong causal chain;
- a thematic reversal;
- a character-specific contribution;
- a fair foreshadowing/payoff pair;
- a useful POV change;
- an image or action that makes the climax legible.

Do not begin with wholesale replacement unless the existing structure genuinely cannot support the intended story.


## 1.5 Scope discipline: read broadly, edit narrowly

When a user names a target Episode or Scene, review its dependencies broadly but keep the proposal patch narrow.

For a request such as “review E07”:
- inspect earlier setup and later payoff as needed;
- edit E07 by default;
- edit another Episode only when a specific E07 revision requires that dependency to change;
- edit shared foreshadowing/Notes only for affected IDs or rows;
- leave consulted-but-unaffected material untouched.

A non-change is not an edit. Never add text such as `既存内容を維持`, `変更なし`, `現状維持`, or equivalent placeholders merely to record that an item was reviewed. Mention preservation in the review prose instead.

Before delivery, inspect every changed object outside the named target and require a one-sentence causal justification. Revert any change without one.

## 2. Causality and chronology

For every major beat, ask:
- What caused this?
- Could the character know this yet?
- Is this action rational given the available options?
- Does a later success accidentally serve as an earlier motive?
- If the obvious action exists, why does the character wait?
- Does the antagonist use the least self-defeating available plan?

Flag future-to-past causality as high priority.

## 3. Episode boundaries

For each Episode:
- local question;
- local climax/answer;
- irreversible difference;
- cost or consequence;
- next Episode cause.

When an Episode is incomplete, state the setup it needs rather than grading missing prose as a failure.

## 4. Scene necessity

Use the sentence:

> This Scene exists to make [character] choose [choice], which changes [state].

If no clear completion is possible, consider merging, moving, or redefining the Scene.

## 5. Character arc and agency

For each major character, track:
- initial want/belief;
- pressure;
- old method;
- failure/cost;
- new choice;
- resulting action.

Test removability: if deleting the character leaves the outcome unchanged, their climax role is probably cosmetic.

## 6. Reader vs character knowledge

Build an informal matrix when needed:

| Beat | Reader knows | Protagonist knows | Other key character knows | False belief |
|---|---|---|---|---|

Pay special attention to POV scenes that conceal facts the POV character is actively thinking about.

## 7. Foreshadowing ledger

For each important payoff, trace:
- seed;
- reinforcement;
- optional misdirection;
- partial reveal;
- payoff;
- changed meaning after payoff.

Avoid introducing all structural prerequisites in the immediately preceding Episode.

## 8. Theme

Check theme in action, not only in dialogue.

Strong climax pattern:

old method fails -> thematic choice -> new behavior -> external consequence -> emotional consequence

Weak pattern:

thematic speech -> unrelated mechanism solves problem

Also test whether the resolution secretly rewards the antagonist's metric. Example: a story saying weak voices have equal value should not resolve only because a weak voice becomes the strongest voice.

## 9. World rules and logistics

Check:
- travel time and spatial order;
- language comprehension;
- institutional authority;
- technical expertise;
- ability range/targeting/limits;
- who controls equipment or records;
- whether emergency procedures existed before the climax.

Prefer earlier setup or restoration of an existing option over a last-minute new capability.

## 10. Antagonist rationality

Ask:
- What exactly is the antagonist still trying to preserve?
- What loss are they willing to concede?
- Why is this risky plan preferable to hiding, fleeing, destroying evidence, or negotiating?
- Does the plan remain rational after each new setback?

When the antagonist is losing, define damage limitation rather than pretending they still expect total victory.

## 11. Emotional climax

Separate:
- practical information;
- institutional/legal confirmation;
- personal desire;
- thematic meaning.

Let the emotional climax occur after the audience understands enough practical context that new technical exposition will not interrupt it.

## 12. Revision report quality

For every recommendation:
- identify the exact target ID;
- describe the current state fairly;
- identify the problem, not just preference;
- propose a concrete alternative;
- explain why it helps;
- list affected Scenes/Episodes/foreshadowing IDs;
- assign priority.

Do not mark user-unapproved revisions as adopted.
